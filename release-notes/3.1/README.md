# Release 3.1 (22)

Paste [play-console.txt](play-console.txt) into Play Console's release-notes
field. It contains all 18 app locales, using Play's language tags. Each locale
has five concise release-note bullets and fewer than 500 Unicode characters.
See [validation.json](validation.json) for individual counts.

The locales match the app's language picker: English (US), Spanish (Spain),
French (France), Arabic, Spanish (Latin America), German, Hindi, Indonesian,
Italian, Japanese, Korean, Polish, Portuguese (Portugal), Russian, Thai,
Turkish, Vietnamese, and Simplified Chinese. Play Console's account-specific
translation settings were not accessed; these are the 18 supported app locales.
