# yes-no-randomizer

The most simple app that answers "Yes" or "No" randomly for any question you ask (or no question at
all)!

See [app quality and release verification](docs/app-quality.md) for memory,
release optimization, and device migration checks.

Questions can be translated on-device when the language picker changes. See
[question translation](docs/question-translation.md) for detection, model downloads,
original-text preservation, and release disclosure requirements.
